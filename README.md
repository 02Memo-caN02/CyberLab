# CyberLab
Personal Cyber Security Research & Education Laboratory

Author: 02Memo-caN02

## Modules
- OSINT: Open Source Intelligence
- NETWORK: Network Discovery & Analysis
- WEB: Web Security Testing
- FORENSICS: Digital Forensics
- CTF: Capture The Flag
- SCRIPTS: Python Automation
- REPORTS: Security Reports
- WORDLISTS: Authorized Lab Wordlists

## Environment
- Android / Termux
- Python 3
- Git / GitHub
- Linux

## Usage
All testing must be performed on systems you own
or have explicit authorization to assess.
